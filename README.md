
# Página Web Personal

Este proyecto es una **página web estática sencilla** desarrollada únicamente con **HTML y CSS**.  
Su objetivo principal es mostrar el uso básico de **etiquetas HTML** y **estilos CSS**.

---

## Descripción del Proyecto

La página está compuesta por **tres secciones principales**:

- **Inicio**: Presentación general sobre mí  
- **Historia**: Un recorrido personal desde la preparatoria, la universidad y mi situación actual  
- **Contacto**: Información básica de contacto

El contenido está enfocado en contar **mi historia personal**, funcionando como un proyecto demostrativo y de aprendizaje.

---

## Tecnologías Utilizadas

- HTML5  
- CSS3  


---

## Cómo Desplegar el Proyecto

Existen dos formas sencillas de visualizar el proyecto:

### Opción 1: Ejecutar de forma local con Live Server
1. Descargar o clonar el repositorio desde GitHub  
2. Abrir la carpeta del proyecto en **Visual Studio Code**  
3. Instalar la extensión **Live Server**  
4. Dar clic derecho sobre `index.html` y seleccionar **Open with Live Server**

### Opción 2: GitHub Pages
El proyecto también puede visualizarse directamente a través del enlace generado por **GitHub Pages**, disponible en la configuración del repositorio.
